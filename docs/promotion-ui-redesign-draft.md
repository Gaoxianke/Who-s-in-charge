# 晋升页现代化UI改造方案

## 一、现状问题诊断

### 1. 视觉层级混乱
- 大量使用 `#F5F4F1` 浅灰背景，缺乏政务主题的庄重感
- 卡片样式统一为白底+1px边框，无阴影、无圆角、无层次感
- Tab栏与内容区缺乏视觉区隔

### 2. 信息展示单一
- 晋升条件以纯文本列表展示，无进度可视化
- 状态指示器仅为简单色块，缺乏动态反馈
- 不同功能区块（派系战/个人战/破格/调任）按钮样式差异大

### 3. 配色方案零散
- 红（`#C82829`）、蓝（`#1D3B5E`）、金（`#B8860B`）三色混用无主次
- 灰色系过深（`#666`、`#888`、`#999`）导致阅读疲劳

---

## 二、改造目标

1. **政务蓝金主题**：以深蓝为底、金色为高光、红色为警示，统一全页配色
2. **卡片式信息架构**：用阴影+圆角+渐变区分信息层级
3. **晋升条件仪表盘**：六项硬门槛用环形进度条/仪表盘可视化
4. **动态状态系统**：条件满足度用色温变化（冷→暖）实时反馈
5. **微交互动效**：卡片悬停抬升、按钮脉冲、进度条流光

## 四、布局结构改造

### 4.1 顶栏（Header）—— 沉浸式政务主题
```
┌─────────────────────────────────────────┐
│  ‹  🏛️ 晋升评审 · 职位争夺               │ ← 深蓝底+金色标题+左边框金色竖线
│     主派：改革派 · 职位争夺制              │
│     [♟ 位置棋盘]                         │
└─────────────────────────────────────────┘
```
- 背景：`bgDeep` + 底部金色渐变线（1px）
- 标题：金色 + 左侧加金色竖条装饰（`borderLeftWidth: 3, borderLeftColor: gold`）
- 返回按钮：圆形 hover 态，金色背景

## 六、动画与交互设计

### 6.1 进入动画
- 页面加载：仪表盘卡片 stagger 入场（每张延迟 50ms，从下方滑入+淡入）
- 进度条：从 0% 动画增长到实际值，持续 800ms，缓动 ease-out

### 6.2 交互反馈
- 卡片 hover（Web端）：`translateY(-2px)` + `shadow` 增强
- 按钮点击：涟漪扩散效果（金色）
- 晋升条件变化：进度条颜色渐变过渡（300ms）
- 争夺结算：分数数字滚动动画（从旧值滚动到新值）

### 6.3 状态变化
```typescript
// 条件满足度颜色映射
const conditionColor = (ratio: number) => {
  if (ratio >= 1.0)  return PROMO_THEME.green;   // 100%+ 绿色
  if (ratio >= 0.75) return PROMO_THEME.gold;    // 75%+ 金色
  if (ratio >= 0.50) return PROMO_THEME.blue;    // 50%+ 蓝色
  return PROMO_THEME.red;                         // <50% 红色
};
```
