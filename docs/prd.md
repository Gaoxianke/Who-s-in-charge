# 需求文档

## 1. 应用概述

### 1.1 应用名称
青云路（华夏干部晋升模拟游戏）

### 1.2 应用描述
本次更新为现有应用「青云路」v57版本执行补充需求R3+R4，仅更新PRD文档，不写代码。

补充需求R3+R4包含五项核心扩充：
1. R3派遣任务：支持派遣在任/待命下属执行巡查/招商/维稳/专案四类任务，派遣期间标记isDispatched=true，归来结算收益
2. R3忠诚与赏赐：新增忠诚度衰减机制、赏赐功能、离职风险与反水机制
3. R4门客/幕僚/亲信：新增私属角色系统（独立于体制编制，不占145编制），包含幕僚/门客/亲信三类
4. R4培养链路：复用党校培训，新增师徒制与举荐入仕
5. R4人事中枢整合页：整合recruit.tsx与subordinates.tsx为统一人事中枢，顶部Tab切换招募/在任干部/私属门客/派遣任务/事件待办

同时保留v57版本的所有功能，包括：部门调任/任命增强（R1.5）、开档/升级自动生成42名下属（R1.5）、编制上限145（R1.5）、招募手动甄选、移除中央选调生、下属四区卡片化UI、政务风、v4派系玩法重构、v3版本功能、职位晋升玩法修复（P1改动）、功能下线等。

## 2. 用户与使用场景

### 2.1 目标用户
- 对官场模拟、策略博弈感兴趣的玩家
- 希望体验派系斗争与职位晋升的玩家
- 喜欢深度策略玩法的玩家
- 希望体验人事管理与资源调配的玩家

### 2.2 核心使用场景
- 玩家派遣下属执行巡查/招商/维稳/专案任务，获取政绩/银两/派系贡献/派系声望/治安收益
- 玩家通过赏赐提升下属忠诚度，避免离职与反水风险
- 玩家招募幕僚/门客/亲信私属角色，获取政绩产出加成/事件探查成功率提升/治安提升效果
- 玩家通过师徒制培养新人，通过举荐入仕引入新干部
- 玩家在人事中枢统一管理招募/在任干部/私属门客/派遣任务/事件待办
- 玩家通过省级席位控制争夺全国派系主导权
- 玩家通过个人职位独立斗争实现职位晋升
- 玩家在派系席位战与个人职位战之间平衡资源投入
- 玩家根据派系实力与个人战力判断争夺胜算
- 玩家申请删除账号后在7天内可恢复，超过7天后管理员执行彻底清除
- 管理员查询已删除账号的历史归档记录
- 玩家在任命/调任下属时选择具体职能部门与岗位角色
- 玩家新建存档或职级升级时，系统自动生成42名下属
- 玩家管理下属名册，编制上限为145人

### 3.2 R3派遣任务系统（新增）

#### 3.2.1 派遣任务类型定义
- 巡查：时长30天，收益政绩+15~30/派系贡献+10，要求ability≥40
- 招商：时长60天，收益银两+150~300/政绩+20，要求ability≥50
- 维稳：时长60天，收益派系声望+/治安+，要求loyalty≥50
- 专案：时长90天，收益派系贡献+30~50/政绩+40，要求ability≥60

#### 3.2.2 派遣流程
- 玩家在在任干部Tab或下属详情弹层点击派遣按钮
- 系统弹出派遣任务选择弹层，显示四类任务及要求
- 玩家选择任务类型，系统校验下属能力是否满足要求
- 校验通过后，系统标记下属isDispatched=true，记录派遣开始时间与任务类型
- 派遣期间，下属在名册中显示「派遣中」状态，不可任命/调任/晋升
- 派遣时长到期后，系统自动结算收益并清除isDispatched标记

#### 3.2.3 派遣失败率计算
- 失败率公式：max(2%, 10%−(ability−40)/5%)
- 示例：ability=40时失败率10%，ability=50时失败率8%，ability=60时失败率6%，ability≥80时失败率2%
- 派遣失败时，无收益且下属loyalty−5

#### 3.2.4 派遣收益结算
- 巡查成功：政绩+15~30（随机），派系贡献+10
- 招商成功：银两+150~300（随机），政绩+20
- 维稳成功：派系声望+（数值待配置），治安+（数值待配置）
- 专案成功：派系贡献+30~50（随机），政绩+40
- 派遣失败：无收益，下属loyalty−5

#### 3.2.5 派遣与P4常态化对抗/公共事件联动钩子
- 预留派遣成功触发公共事件的钩子（如招商成功触发经济发展事件）
- 预留派遣失败触发对抗事件的钩子（如专案失败触发派系冲突事件）
- 具体联动逻辑在P4常态化对抗/公共事件模块中实现

#### 3.2.6 派遣任务Tab
- 进行中任务列表：显示派遣中的下属、任务类型、剩余时长、预期收益
- 已完成任务列表：显示已完成的派遣任务、实际收益、成功/失败状态
- 任务详情弹层：显示任务详情、下属信息、收益明细

### 3.3 R3忠诚与赏赐系统（新增）

#### 3.3.1 忠诚度衰减机制
- 下属忠诚度（loyalty）每日衰减−0.05
- 忠诚度<20时，触发随机离职风险（每日判定，概率待配置）
- 忠诚度<10时，触发反水机制（贪腐/巡查事件提供线索或叛变，复用eventType框架）

#### 3.3.2 赏赐功能
- 玩家在下属详情弹层或在任干部Tab点击赏赐按钮
- 系统弹出赏赐选择弹层，显示两种赏赐方式：
  + 银两赏赐：消耗银两50，下属loyalty+5~15（随机）
  + 政绩赏赐：消耗政绩10，下属loyalty+5~15（随机）
- 玩家选择赏赐方式，系统校验资源是否充足
- 校验通过后，系统扣除资源，增加下属忠诚度

#### 3.3.3 下属档案卡显示
- 下属详情弹层新增忠诚度进度条，显示当前忠诚度值与状态（正常/风险/危险）
- 下属详情弹层新增赏赐按钮，点击后弹出赏赐选择弹层
- 在任干部Tab列表卡片显示忠诚度图标与数值

#### 3.3.4 离职与反水处理
- 离职：下属从subordinates数组中移除，编制−1，记录离职历史
- 反水：触发反水事件（复用eventType框架），事件类型包括：
  + 贪腐线索：下属提供玩家贪腐证据，增加玩家风险值
  + 巡查事件：下属在巡查中故意制造问题，降低玩家政绩
  + 叛变：下属投靠竞争派系，降低玩家派系影响力

### 3.4 R4门客/幕僚/亲信系统（新增）

#### 3.4.1 私属角色类型定义
- 幕僚（政务参谋）：招募需人脉≥50，效果政绩产出+5%
- 门客（情报）：招募需银两≥200且人脉≥30，效果事件探查成功率+/降低不确定性
- 亲信（执行/护卫）：招募需银两≥300，效果治安+/降低反水概率

#### 3.4.2 私属角色数据结构
- 新增retainer表/类型（Retainer）
- 字段：type（幕僚/门客/亲信）、loyalty（初始50~80）、ability、bonus（加成效果）、name、recruited_at
- 私属角色独立于体制编制，不占145编制

#### 3.4.3 私属招募流程
- 玩家在私属门客Tab点击招募入口
- 系统弹出私属招募弹层，显示三类私属及招募条件
- 玩家选择私属类型，系统校验资源是否满足招募条件
- 校验通过后，系统扣除资源，生成私属角色并写入retainer表
- 私属角色在私属门客Tab列表中显示

#### 3.4.4 私属忠诚度与赏赐
- 私属角色有独立loyalty字段（初始50~80）
- 私属忠诚度每日衰减−0.05
- 私属忠诚度<20时，触发流失风险（私属离开，失去加成效果）
- 私属忠诚度<10时，触发叛离风险（私属投靠竞争派系，降低玩家派系影响力）
- 玩家可通过赏赐提升私属忠诚度：消耗银两50，私属loyalty+5~15（随机）

#### 3.4.5 私属加成效果
- 幕僚：玩家政绩产出+5%（全局加成）
- 门客：事件探查成功率+（数值待配置），降低不确定性（数值待配置）
- 亲信：玩家治安+（数值待配置），降低下属反水概率（数值待配置）

#### 3.4.6 私属门客Tab
- 私属列表：显示已招募的幕僚/门客/亲信，卡片化展示
- 招募入口：点击后弹出私属招募弹层
- 赏赐按钮：点击后弹出赏赐选择弹层
- 私属详情弹层：显示私属信息、忠诚度进度条、加成效果、赏赐按钮

### 3.5 R4培养链路（新增）

#### 3.5.1 党校培训（复用现有功能）
- 复用现有trainAtPartySchool功能
- 下属通过党校培训提升ability

#### 3.5.2 师徒制（新增）
- 玩家在下属详情弹层选择高阶下属（ability≥60）作为师傅
- 玩家选择低阶下属（ability<40）作为徒弟
- 系统建立师徒关系，徒弟ability成长速度+20%
- 师徒关系持续时间待配置（如180天）
- 师徒关系结束后，徒弟ability成长速度恢复正常

#### 3.5.3 举荐入仕（新增）
- 玩家在招募Tab点击举荐入仕入口
- 系统弹出举荐入仕弹层，显示举荐条件：
  + 候选人年龄≥18（呼应P7年龄规则）
  + 编制未满（已用编制<145）
  + 玩家派系贡献≥（数值待配置）
- 玩家选择候选人，系统校验举荐条件
- 校验通过后，系统扣除派系贡献，将候选人加入subordinates数组，编制+1
- 举荐入仕不豁免年龄+编制+贡献全套校验

## 4. 业务规则与逻辑

### 4.1 R3派遣任务规则（新增）

#### 4.1.1 派遣资格校验规则
- 巡查：ability≥40
- 招商：ability≥50
- 维稳：loyalty≥50
- 专案：ability≥60
- 下属必须为在任或待命状态，不可为派遣中状态

#### 4.1.2 派遣期间限制规则
- 派遣期间标记isDispatched=true
- 派遣期间不可任命/调任/晋升该下属
- 派遣期间下属在名册中显示「派遣中」状态

#### 4.1.3 派遣时长计算规则
- 巡查：30天
- 招商：60天
- 维稳：60天
- 专案：90天
- 派遣开始时记录派遣开始时间（dispatch_start_time）
- 派遣结束时间 = 派遣开始时间 + 派遣时长

#### 4.1.4 派遣失败率计算规则
- 失败率公式：max(2%, 10%−(ability−40)/5%)
- 失败率最低为2%，最高为10%
- 派遣结算时随机判定是否失败

#### 4.1.5 派遣收益结算规则
- 巡查成功：政绩+15~30（随机），派系贡献+10
- 招商成功：银两+150~300（随机），政绩+20
- 维稳成功：派系声望+（数值待配置），治安+（数值待配置）
- 专案成功：派系贡献+30~50（随机），政绩+40
- 派遣失败：无收益，下属loyalty−5
- 派遣结束后清除isDispatched标记

#### 4.1.6 派遣与P4联动钩子规则
- 预留派遣成功触发公共事件的钩子
- 预留派遣失败触发对抗事件的钩子
- 具体联动逻辑在P4常态化对抗/公共事件模块中实现

### 4.2 R3忠诚与赏赐规则（新增）

#### 4.2.1 忠诚度衰减规则
- 下属忠诚度每日衰减−0.05
- 私属忠诚度每日衰减−0.05
- 衰减在每日天数推进时执行

#### 4.2.2 离职风险规则
- 下属忠诚度<20时，每日判定离职风险
- 离职概率待配置（如5%）
- 离职时下属从subordinates数组中移除，编制−1
- 记录离职历史

#### 4.2.3 反水机制规则
- 下属忠诚度<10时，触发反水事件
- 反水事件类型：
  + 贪腐线索：增加玩家风险值（数值待配置）
  + 巡查事件：降低玩家政绩（数值待配置）
  + 叛变：降低玩家派系影响力（数值待配置）
- 反水事件复用eventType框架

#### 4.2.4 赏赐规则
- 银两赏赐：消耗银两50，下属loyalty+5~15（随机）
- 政绩赏赐：消耗政绩10，下属loyalty+5~15（随机）
- 赏赐前校验资源是否充足
- 赏赐后立即增加下属忠诚度

#### 4.2.5 私属流失与叛离规则
- 私属忠诚度<20时，触发流失风险
- 流失时私属从retainer表中移除，失去加成效果
- 私属忠诚度<10时，触发叛离风险
- 叛离时降低玩家派系影响力（数值待配置）

## 6. 验收标准

1. 玩家在在任干部Tab点击派遣按钮，系统弹出派遣任务选择弹层，显示巡查/招商/维稳/专案四类任务及要求
2. 玩家选择派遣任务类型，系统校验下属能力是否满足要求，校验通过后标记isDispatched=true，记录派遣开始时间与任务类型
3. 派遣期间，下属在名册中显示「派遣中」状态，不可任命/调任/晋升
4. 派遣时长到期后，系统自动结算收益，根据失败率公式判定成功/失败，成功时增加对应收益，失败时下属loyalty−5，清除isDispatched标记
5. 玩家在派遣任务Tab查看进行中任务列表与已完成任务列表，点击任务卡片弹出详情弹层，显示任务详情、下属信息、收益明细
6. 玩家在下属详情弹层查看忠诚度进度条，显示当前忠诚度值与状态（正常/风险/危险）
7. 玩家在下属详情弹层点击赏赐按钮，系统弹出赏赐选择弹层，显示银两赏赐与政绩赏赐两种方式
8. 玩家选择赏赐方式，系统校验资源是否充足，校验通过后扣除资源，增加下属忠诚度+5~15（随机）
9. 系统每日天数推进时，下属忠诚度衰减−0.05，忠诚度<20时判定离职风险，忠诚度<10时触发反水事件
10. 玩家在私属门客Tab点击招募入口，系统弹出私属招募弹层，显示幕僚/门客/亲信三类私属及招募条件
11. 玩家选择私属类型，系统校验资源是否满足招募条件，校验通过后扣除资源，生成私属角色并写入retainer表
12. 私属招募成功后，系统立即生效加成效果（幕僚政绩产出+5%，门客事件探查成功率+，亲信治安+/降低反水概率）
13. 玩家在私属详情弹层查看忠诚度进度条，点击赏赐按钮，系统弹出赏赐选择弹层，消耗银两50增加私属loyalty+5~15（随机）
14. 系统每日天数推进时，私属忠诚度衰减−0.05，忠诚度<20时触发流失风险，忠诚度<10时触发叛离风险
15. 玩家在下属详情弹层选择高阶下属（ability≥60）作为师傅，选择低阶下属（ability<40）作为徒弟，系统建立师徒关系，徒弟ability成长速度+20%
16. 师徒关系持续180天后自动结束，徒弟ability成长速度恢复正常
17. 玩家在招募Tab点击举荐入仕入口，系统弹出举荐入仕弹层，显示举荐条件（候选人年龄≥18、编制未满、玩家派系贡献≥配置值）
18. 玩家选择候选人，系统校验举荐条件，校验通过后扣除派系贡献，将候选人加入subordinates数组，编制+1
19. 玩家在人事中枢页面顶部Tab导航切换招募/在任干部/私属门客/派遣任务/事件待办，系统显示对应内容区域
20. 玩家在招募Tab查看候选人列表（卡片化），点击候选人卡片弹出详情弹层，显示候选人信息与招募按钮
21. 玩家在在任干部Tab查看下属名册列表（卡片化），点击下属卡片弹出详情弹层，显示下属信息、忠诚度进度条、任命/调任/赏赐/派遣按钮
22. 玩家在私属门客Tab查看私属列表（卡片化），点击私属卡片弹出详情弹层，显示私属信息、忠诚度进度条、加成效果、赏赐按钮
23. 玩家在派遣任务Tab查看进行中任务列表与已完成任务列表，点击任务卡片弹出详情弹层，显示任务详情、下属信息、收益明细
24. 玩家在事件待办Tab查看待处理事件列表（如离职风险、反水事件、派遣任务完成等），点击事件卡片弹出详情弹层，显示事件详情与处理按钮
25. 系统使用政务风样式（政务蓝#1B3A6B/中国红#C8161D）渲染人事中枢页面
26. 系统共享档案卡组件，确保招募Tab、在任干部Tab、私属门客Tab使用统一档案卡样式
27. 系统在player_saves表中新增/复用silver字段与connections字段，用于门客招募、亲信招募、赏赐
28. 玩家招商派遣任务成功后，系统增加银两+150~300（随机），政绩+20
29. 玩家赏赐消耗银两50或政绩10，系统校验资源是否充足，校验通过后扣除资源
30. 玩家派遣专案任务成功后，系统增加派系贡献+30~50（随机），计入P2派系贡献池
