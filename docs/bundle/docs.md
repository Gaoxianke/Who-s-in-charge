# 需求文档

## 1. 应用概述

### 1.1 应用名称
青云路（华夏干部晋升模拟游戏）

### 1.2 应用描述
本次更新为现有应用「青云路」进行v4派系玩法重构，在原有基础上新增两层玩法：省级席位控制（全国棋盘）与个人职位独立斗争。核心调整包括：
1. 新增省级席位控制机制：以全国34个省级行政区为棋盘，派系控制全国总席位比例≥80%即获胜
2. 重构斗争力计算：完全配置化，禁止函数内硬编码数字，新增派系实力计算与个人战力计算
3. 新增个人职位独立斗争：玩家必须先点选具体目标职位才能发起职位争夺战，独立于派系席位战
4. 新增省级席位地图UI组件：展示全国席位控制度、五派席位分布、个人职位战面板
5. 保留原有派系委托/密谋/叛逃(v3)玩法，确保不被破坏
6. 保留位置棋盘UI组件，确保颜色/标签从配置读取
7. 保留四宫格结局机制：派系胜负×个人胜负四种组合

同时保留v3版本的以下功能：
- 彻底删除「上级（上司）关系经营」与「上司任务」两大子系统
- 十项功能：数据清理SQL执行、自动清理定时任务、多数据库选择与容量管理机制、测试码生成统计修复、账号申诉管理功能重构、NPC姓名同步到名册、管理员账户赦免所有审查设定、临时申诉功能、阶段五领导贪腐与证据博弈玩法、阶段六派系斗争与站队博弈玩法
- 调整后台「创建普通账号」功能权限
- 配置中心化架构
- 派系晋升联动与派系玩法扩展

- 玩家通过个人职位独立斗争实现职位晋升

### 3.2 省级席位控制功能

#### 3.2.1 省级席位定义
- 以全国34个省级行政区为棋盘
- 每省席位数计算公式：round(该省下辖地级市数量 × 1.8)，clamp到[3, 18]
- 省级行政区列表与下辖地市数使用现有PROVINCE_LIST / PROVINCE_CITY_MAP（在types/game.ts里）

#### 3.2.2 派系席位控制
- 派系控制全国总席位比例≥80%即「省级席位战获胜」
- 本轮斗争提前收官：strugglePhase置truce、解除factionPromotionLocked
- 等待下一个5年周期（WIND_CYCLE_DAYS=1825天）
- 若到周期边界仍未达80%，本轮争夺标记expired，下一轮重选

#### 3.2.3 席位控制度计算
- 统计各派系控制的席位数
- 计算各派系控制全国总席位的比例
- 判断是否有派系达到80%获胜阈值

### 3.3 斗争力计算重构

#### 3.3.1 配置对象定义
新增lib/provinceSeatSystem.ts，定义以下配置对象：
- FACTION_POWER_WEIGHTS：各派系实力构成权重（relation、influence、merit、intelligence、treasury）
- FACTION_DOMAIN_BONUS：竞争派系在不同地域类型的加成
  + 改革开放系在直辖市/沿海省加成
  + 地方实力派在边疆/民族地区加成
  + 清流在文化大省加成
  + 地域类型从PROVINCE_CITY_MAP的province类型字段派生
- VICTORY_THRESHOLD：省级席位获胜阈值（0.8）
- CONTEST_BLEND：个人职位战派系与个人贡献比例（faction: 0.1, personal: 0.9）
- CONTEST_COSTS：争夺成本配置
  + personalContest：个人职位战成本（merit: 80, cooldownDays: 30）
  + provinceSeat：省级席位战冷却（cooldownDays: 90）

#### 3.3.2 派系实力计算
- calcFactionPower(save, faction)：用FACTION_POWER_WEIGHTS加权计算各派实力分
- 输入：玩家存档、派系ID
- 计算：关系值 × 权重 + 影响力 × 权重 + 功绩 × 权重 + 情报 × 权重 + 经费池 × 权重
- 输出：派系实力分数

#### 3.3.3 个人战力计算
- calcPersonalPower(save)：个人独立战力计算
- 计算公式：政绩 + 民心 + 经济 + 廉洁 + 事件处理 + 人脉 + 任期稳定
- 各项权重从配置读取
- 数据来源：PlayerSave真实字段（meritPoints, popularSupport, taxRevenue/economy, integrity, eventsHandled, factionInfluence, rankLevel稳定度等）

#### 3.3.4 个人职位争夺判定
- resolvePersonalContest(save, bandFactions)：个人职位争夺结算
- 计算玩家战力：CONTEST_BLEND.faction × playerFactionPower + CONTEST_BLEND.personal × personalPower
- 计算竞争派系战力：竞争派系实力加权之和
- 判定胜负：玩家战力 >= 竞争派系战力
- 返回：{ win, sYou, sOpp, detail }

### 3.4 个人职位独立斗争

#### 3.4.1 目标职位选择
- 晋升页改为：玩家必须先点选一个具体目标职位

- 校验冷却时间：personalContestCooldownUntil距当前时间是否超过30天

#### 3.4.3 职位争夺战结算
- 仅win才落档晋升：rankLevel+1、playerPosition=目标职位、cityName=目标城市
- 设置30天冷却：personalContestCooldownUntil = 当前gameDays + 30
- 记录争夺历史：personalContestHistory新增本次争夺记录
- 个人战win只晋升玩家，不结束派系回合

### 3.5 省级席位与个人战的关系

#### 3.5.1 双轨独立机制
- 派系省级席位战（≥80%控制）走独立赛道
- 个人职位战走独立赛道（10%派系+90%个人）
- 两者互不干扰，独立结算

#### 3.5.2 四宫格结局保留
- 派系胜+个人胜：最佳结局，玩家晋升成功，派系进入休战期
- 派系胜+个人负：玩家不晋升，派系进入休战期
- 派系负+个人胜：玩家晋升成功，但仍受派系失败惩罚
- 派系负+个人负：最糟结局，玩家不晋升，受派系失败惩罚

#### 3.5.3 派系败惩罚
- 沿用v2惩罚机制：本派影响力-15、本派关系-12、民心-6、经济-8、失势期180天

- 派系负+个人胜：玩家晋升成功，但仍受派系失败惩罚
- 派系负+个人负：玩家不晋升，受派系失败惩罚

#### 4.4.3 派系败惩罚规则
- 本派影响力-15
- 本派关系-12
- 民心-6
- 经济-8
- 失势期180天
- 调用applyFactionLossPenalty执行惩罚

### 4.5 数据存储规则

#### 4.5.1 新增类型定义
- ProvinceSeat：省级席位对象
- NationalSeatControl：全国席位控制对象
- PersonalContest：个人职位争夺对象
- ContestDetail：争夺详情对象

#### 4.5.2 PlayerSave新增字段
- provinceSeatControl：Record<province, factionId>，记录各省席位控制派系
- personalContestCooldownUntil：number，个人职位战冷却截止时间
- personalContestHistory：ContestDetail[]，个人职位战历史记录

#### 4.5.3 配置对象存储
- FACTION_POWER_WEIGHTS：派系实力权重配置
- FACTION_DOMAIN_BONUS：地域加成配置
- VICTORY_THRESHOLD：获胜阈值配置
- CONTEST_BLEND：争夺贡献比例配置
- CONTEST_COSTS：争夺成本配置

### 4.6 周期边界处理规则

#### 4.6.1 天数推进规则
- 每WIND_CYCLE_DAYS=1825天为一个周期
- 天数推进到周期边界时触发省级席位结算

#### 4.6.2 省级席位结算规则
- 调用resolveNationalSeatControl结算全国席位控制
- 若有派系达标（≥80%）：strugglePhase置truce、解除factionPromotionLocked
- 若到周期边界仍未达标：本轮争夺标记expired

## 6. 验收标准

1. 玩家在晋升页面查看省级席位地图组件，顶部显示全国席位控制度进度条与80%获胜阈值线（醒目标注），显示五派席位分布（按FACTION_LABEL / FACTION_COLOR），显示各省列表（该省席位数、当前主导派系、玩家是否在该省有职位），显示个人职位战面板（目标职位选择器、战力预估、花费/冷却提示），显示竞争派系加成说明
2. 系统根据PROVINCE_LIST / PROVINCE_CITY_MAP计算每省席位数（round(该省下辖地级市数量 × 1.8)，clamp到[3, 18]），统计各派系控制的席位数，计算各派系控制全国总席位的比例，判断是否有派系达到80%获胜阈值
3. 当某派系控制全国总席位比例≥80%时，系统触发省级席位战获胜，本轮斗争提前收官（strugglePhase置truce、解除factionPromotionLocked），等待下一个5年周期（WIND_CYCLE_DAYS=1825天）
4. 游戏天数推进到周期边界（gameDays跨过WIND_CYCLE_DAYS倍数）时，系统调用resolveNationalSeatControl结算全国席位控制，若有派系达标则truce+解除冻结，若到边界仍未达标则本轮争夺标记expired
5. 系统使用FACTION_POWER_WEIGHTS加权计算派系实力分（关系值 × 权重 + 影响力 × 权重 + 功绩 × 权重 + 情报 × 权重 + 经费池 × 权重），权重从配置对象读取，禁止硬编码
6. 系统计算个人独立战力（政绩 + 民心 + 经济 + 廉洁 + 事件处理 + 人脉 + 任期稳定），各项权重从配置读取，数据来源为PlayerSave真实字段（meritPoints, popularSupport, taxRevenue/economy, integrity, eventsHandled, factionInfluence, rankLevel稳定度等）
7. 玩家在晋升页面点选具体目标职位（复用COUNTY/CITY/SUB_PROVINCE/PROVINCE_OFFICIAL_POSITIONS官职架构），系统显示目标职位名称、职级、所在城市
8. 玩家点击目标职位发起职位争夺战，系统校验冷却时间（personalContestCooldownUntil距当前时间是否超过30天）与功绩门槛（meritPoints >= 80），校验通过后扣除80功绩点数，调用resolvePersonalContest判定胜负
9. 系统计算玩家战力（CONTEST_BLEND.faction × playerFactionPower + CONTEST_BLEND.personal × personalPower），计算竞争派系战力（竞争派系实力加权之和），判定胜负（玩家战力 >= 竞争派系战力），返回{ win, sYou, sOpp, detail }
10. 玩家职位争夺战win时，系统落档晋升（rankLevel+1、playerPosition=目标职位、cityName=目标城市），设置30天冷却（personalContestCooldownUntil = 当前gameDays + 30），记录争夺历史（personalContestHistory新增本次争夺记录），个人战win只晋升玩家，不结束派系回合
11. 玩家在派系胜+个人胜时，系统显示最佳结局提示，玩家晋升成功，派系进入休战期
12. 玩家在派系胜+个人负时，系统显示玩家不晋升提示，派系进入休战期
13. 玩家在派系负+个人胜时，系统显示玩家晋升成功但仍受派系失败惩罚提示，调用applyFactionLossPenalty执行惩罚（本派影响力-15、本派关系-12、民心-6、经济-8、失势期180天）
14. 玩家在派系负+个人负时，系统显示最糟结局提示，玩家不晋升，受派系失败惩罚
15. 系统从FACTION_DOMAIN_BONUS读取竞争派系在不同地域类型的加成系数，地域类型从PROVINCE_CITY_MAP的province类型字段派生，计算派系实力时应用地域加成
16. 玩家在省级席位地图组件查看战力预估，系统显示派系10% + 个人90%分解条，显示花费80功绩点数与30天冷却提示
17. 玩家在位置棋盘组件查看席位网格按holderFaction着色，枢纽席位标记★，玩家目标席位显示虚线环，顶部显示派系控制度进度条，底部显示四宫格结局实时提示
18. 系统在PlayerSave中新增provinceSeatControl字段（Record<province, factionId>），记录各省席位控制派系，新增personalContestCooldownUntil字段（number），记录个人职位战冷却截止时间，新增personalContestHistory字段（ContestDetail[]），记录个人职位战历史记录
19. 系统在lib/provinceSeatSystem.ts中定义配置对象（FACTION_POWER_WEIGHTS、FACTION_DOMAIN_BONUS、VICTORY_THRESHOLD、CONTEST_BLEND、CONTEST_COSTS），所有数值参数从配置对象读取，禁止硬编码
20. 系统在lib/promotionFaction.ts中调用provinceSeatSystem的calcFactionPower / resolvePersonalContest，保持applyContestWin / applyFactionLossPenalty不变
21. 系统在ctx/GameContext.tsx中天数推进时接省级席位结算resolveNationalSeatControl，达标则truce+解除冻结，周期边界expired
22. 系统在app/(app)/promotion.tsx、components/promotion/ConditionsTab.tsx、components/promotion/PromotionFlow.tsx中接入目标职位选择器和个人职位战（花费80功绩+30天冷却门控）
23. 玩家冷却时间未到尝试发起争夺时，系统显示「冷却时间未到，请等待X天后再试」提示，禁止发起
24. 玩家功绩点数不足80尝试发起争夺时，系统显示「功绩点数不足，需要80点功绩」提示，禁止发起
25. 系统保留原有派系委托/密谋/叛逃(v3)玩法，确保不被破坏，玩家可在派系页面查看委托列表、密谋行动入口、叛逃换系入口
26. 系统保留v3版本的数据清理功能、多数据库容量管理、测试码生成统计修复、账号申诉管理功能重构、NPC姓名同步到名册、管理员账户赦免所有审查设定、临时申诉功能、阶段五领导贪腐与证据博弈玩法、阶段六派系斗争与站队博弈玩法、配置中心化架构、派系晋升联动与派系玩法扩展
27. 管理员在管理后台点击「立即清理」按钮，系统显示确认弹窗，管理员点击确认后依次执行三条清理SQL，执行完成后显示清理结果
28. 系统在每天中午12:00（UTC时间04:00）自动执行清理任务，执行完成后生成清理报告，报告存储至清理日志表，管理员可在管理后台查看历史清理报告
29. 玩家在注册页面看到可用节点列表，每个节点显示节点名称、当前容量、剩余容量、在线玩家数，节点状态标识为绿色（正常）、黄色（即将满）或红色（已满），系统自动推荐剩余容量最大的节点并高亮显示

36. 玩家在游戏中查看当前贪腐风险值与证据值，选择「收受贿赂」行动后获得资金与政绩，风险值与证据值同时增加，数值变化立即显示在界面上
37. 玩家选择「销毁证据」行动，消耗资金与精力后证据值降低，系统显示证据值变化结果
38. 玩家选择「收买证人」行动，消耗资金后系统判定成功或失败，成功时证据值降低，失败时证据值增加并显示失败提示
39. 玩家证据值达到80时，系统触发纪委调查事件，显示调查事件内容
40. 玩家证据值达到100时，系统触发贪腐败露落马结局，显示结局画面，游戏结束，存档标记为gameOverType='corruption'
41. 玩家在游戏中查看当前三大派系影响力（改革派、务实派、中立派），选择「公开站队」行动支持改革派，改革派影响力大幅提升，务实派与中立派影响力下降
42. 玩家选择「暗中输送」行动，消耗资金后务实派影响力小幅提升，系统显示影响力变化结果
43. 系统随机触发派系冲突事件（资源争夺/政策分歧/职责越位），玩家选择支持某派系或调停冲突，系统更新派系影响力并显示变化结果
44. 玩家改革派影响力超过阈值（从配置文件读取），系统触发「被派系绑架」风险提示，决策通过率下降，系统显示风险提示内容
45. 玩家长期保持三大派系影响力均衡（差值小于阈值），系统触发「平衡之道」成就，显示成就提示内容
46. 管理员在配置管理后台编辑贪腐系统配置文件，修改风险值衰减速率参数，保存后游戏内风险值衰减速率立即更新
47. 管理员在配置管理后台编辑派系系统配置文件，修改公开站队影响力提升值，保存后游戏内公开站队行动效果立即更新
48. 玩家在晋升页面查看位置棋盘，棋盘显示所有席位按holderFaction着色，枢纽席位标记★，玩家目标席位显示虚线环，顶部显示各派系控制度进度条，底部显示四宫格结局实时提示
49. 玩家在晋升页面点击目标职位，系统发起该职位争夺，生成PromotionContest对象，计算sYou与sOpp，显示争夺结果预测
50. 玩家派系整体胜且玩家职务胜时，系统更新rankLevel、rankName、playerPosition、cityName，显示晋升成功提示，派系进入休战期
51. 玩家派系整体负时，系统调用applyFactionLossPenalty，本派影响力-15、关系值-12、popularSupport-6、taxRevenue-8、factionSetbackUntilDay=day+180、本周期继续冻结factionPromotionLocked=true，显示派系失败惩罚提示
52. 玩家在派系页面查看委托列表，每个委托显示委托内容、奖励、惩罚，玩家点击完成委托后获得奖励（关系值、影响力、经费池、政绩点数+25~35），系统显示奖励获得提示
53. 玩家在派系页面点击密谋行动入口，选择密谋类型（report/discord/proxy/preempt）与目标派系，系统扣减50政绩点数，执行暴露判定，若暴露则riskValue+12、关系值-8、累计covertExposedCount，显示密谋行动结果
54. 玩家在派系页面点击叛逃换系入口，系统校验叛逃条件（失势期禁、冷却期禁、立案禁、目标派声望≥L2、不得投奔死敌、政绩点数≥100），校验通过后扣减100政绩点数，执行叛逃，旧派关系值压底20、影响力-20、新派关系值基线40，进入365天冷却，本周期冻结，显示叛逃成功提示
55. 玩家政绩点数不足50时尝试执行密谋行动，系统显示「政绩点数不足，无法执行密谋行动」提示
56. 玩家政绩点数不足100时尝试执行叛逃换系，系统显示「政绩点数不足，无法叛逃换系」提示
